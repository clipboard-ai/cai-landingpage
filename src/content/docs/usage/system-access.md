# System Access

Actions can use your Calendar, Contacts, and Reminders. Cai never asks up front: macOS shows its standard permission prompt the first time an action actually needs one, and you can change any grant later in System Settings.

**Settings → Connections → System Access** shows the status of every grant in one place:

- **Calendar** — read events and add new ones
- **Reminders** — read and create reminders
- **Contacts** — look up people you mention
- **Accessibility** — powers the ⌥C selection capture and inline replace
- **Automation** — lets destinations control other apps via AppleScript

If a grant is missing when an action needs it, Cai tells you and offers to open the right pane in System Settings.
